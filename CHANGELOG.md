# 0.1.0+1

- Initial release of `kuwe_flutter_starter`.
- Production-ready Flutter project template featuring:
  - Architecture: Feature-first structure with service locator (`get_it`).
  - State Management: BLoC pattern (`flutter_bloc`).
  - Navigation: Type-safe routing with `auto_route`.
  - Networking: `dio` with logging and retry interceptors.
  - Backend / Auth: Firebase Core, Firebase Auth, Cloud Firestore, and Firebase Messaging.
  - Multi-Environment: Separate development and production configurations.
  - Localization: Flutter internationalization (`flutter_localizations`, ARB files).
  - Code & Asset Generation: `build_runner`, `flutter_gen`, and `envied`.
